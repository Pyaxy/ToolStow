AI / 自动化 API 参考

使用 Authorization: Bearer $TOOLSTOW_API_KEY 访问（不可用于登录后台或修改站点设置）。

  • GET /api/admin/tools
    列出所有工具（包含草稿）
  • POST /api/admin/tools/upload
    multipart/form-data 字段 file 上传或覆盖 .zip
  • PATCH /api/admin/tools/{id}
    JSON {"draft": true | false} 切换发布状态
  • DELETE /api/admin/tools/{id}
    删除指定工具及其目录
cURL 示例 
curl -X POST \
  -H "Authorization: Bearer $TOOLSTOW_API_KEY" \
  -F "file=@my-tool.zip" \
  http://127.0.0.1:8080/api/admin/tools/upload

确认删除工具
